The repo on GitHub How a run goes

The exercise book: a run in ordinary language

The script is a small interactive Python program in time.py. It asks for one assignment name per line at the > prompt, then asks how many minutes each one will take, then prints a single total: It will take you X minutes to complete your homework.

The word done does double duty. Typed in any case, it is both the last thing you enter in the list and the signal that closes it. The word itself is never counted as an assignment, blank lines are skipped, and ending the input, for example with Ctrl-D, closes the list the same way.

What the board does not do

It keeps no record. Nothing is saved between runs.

note one

It converts nothing. It answers in the same minutes it was fed, so an hour and a half must arrive as ninety.

90, not 1.5 hours

Bad figures are refused. Non-numeric input, negative numbers, and the values nan and inf are rejected with a message, and the same assignment is asked again. Decimals such as 1.5 are accepted.

Tests: python3 -m unittest runs scripted-input cases in test_time.py. If the input ends in the middle of entering times, the script prints Input ended before all times were entered. and exits with status 1 instead of a traceback.
